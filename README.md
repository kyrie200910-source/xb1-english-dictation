# 选必一复习本

高中选择性必修一复习工具：新外研版英语 **单词默写 + 邀请信作文模板**，人教版生物《稳态与调节》**第1–2章问答卡**（顶部切换科目）。纯静态单文件网页，下载 `index.html` 双击即可使用，也可以直接在线打开：

**https://kyrie200910-source.github.io/xb1-english-dictation/**

## 功能

### 英语

- **默写**：按单元选范围（Unit 2–5，Unit 5 至 p.69 `generate` 之前），屏幕只显示中文和词性，纸上写英文，按空格翻答案，J / F 自评对错。单词随机打乱，错过的词优先出现。
- **错题本**：写错的词自动收录，连续两次写对才移出；可只默写错题本。
- **单词表**：全部词条一览，标 `*` 的为课本拓展词汇，可用于和课本核对。
- **打印默写纸**：生成 A4 默写卷（左中文、右留空、答案另页），随机顺序。
- **邀请信模板**：填入题目信息即可生成整封邀请信；附三段式骨架、老师课件高分句库和范文。

### 生物（人教版 稳态与调节 第1–2章）

- **问答卡**：85 张，覆盖 1.1 细胞生活的环境 → 2.5 人脑的高级功能。先回忆再翻答案，自评 会 / 模糊 / 不会；按记忆曲线安排下次出现（1、3、7、14、30、60 天），不会的卡本轮重做。
- **知识框架**：每节要点 + 易错点，考前快速通读。
- **掌握情况**：按节统计掌握率与今日到期数。

进度保存在浏览器本地（localStorage），不上传任何数据。
