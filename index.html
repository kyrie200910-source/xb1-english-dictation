非谓语动词（作主语、宾语、表语）· 我的错题考点

来自学校练习卷上画红圈的 17 道错题（另加第 1 题）。归为 5 类，每类先看结论，再做“错题重做”和“专项训练”。

A　动名词作主语（含被动式、复合结构）

错题 4、12、38、44、48（另 1 题也错在这）

句子缺主语时，用 doing（不能用过去分词 done）。逻辑主语“被”做 → being done：Being examined twice a year is the rule（车“被检查”）；Being exposed to different cultures helps（“被接触到”= 接触）；Being admitted into a key university makes him cheerful。要点明动作执行者时用所有格 + doing：The girl's being educated in… was what her parents wished for。表示“有…”用 there being：dream of there being a place。谓语动词用单数。

B　主动形式表被动：be worth doing / need·want·require doing

错题 6、20、42、50

这四个结构后面接 doing 表示被动意义，不用 to be done：The film is worth watching；it requires checking = requires to be checked；awareness needs improving = needs to be improved。第 6 题 the things you find worth doing：things 是 find 的宾语，所以不能再加 them（排除 A、C）；worth 后直接 doing（排除 B）。第 50 题主语 awareness 单数 → needs。

C　只接 doing 的动词和 to 是介词的短语

错题 3、15、18、43

admit / deny / avoid / mind / enjoy / finish / practise / suggest / consider（考虑）/ keep / miss / risk / delay / escape / imagine + doing：admitted breaking the window。object to / look forward to / be used to / get down to / devote…to / pay attention to / stick to / lead to 里的 to 是介词，后接 doing：object to having；look forward to seeing（第 18 题 as he himself is [looking forward] to seeing her）。object 是不及物动词，没有被动 be objected。have difficulty / trouble / a hard time (in) doing：the difficulty new graduates have adapting。

D　it 作形式主语 / 形式宾语的固定句型

错题 19、46、47

it is no use / no good / useless + doing：find it no use arguing；think it any good forbidding smoking。think / find / consider / make + it + adj/n + to do：think it important to keep reading（it 是形式宾语，不能用 that）。区分：真正主语/宾语是 to do 时用 it + to do；是“做某事没用”时用 no use doing。

E　意义不同的两用动词：try / regret / mean / forget / remember / stop

错题 8、46（25 也在这类）

try to do 努力做，try doing 试着做（Why not try going by plane 换个方式试试）；regret doing 后悔做过（regret failing the exam），regret to do 遗憾地要做（regret to tell you）；mean to do 打算，mean doing 意味着；forget / remember to do 未做，doing 已做；stop to do 停下来去做，stop doing 停止做。Why not + 动词原形。
